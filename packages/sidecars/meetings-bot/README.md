# @ikenga/pkg-meetings-bot

**Retired — use [`com.ikenga.meetings`](../../apps/meetings) (bundles this).**

`com.ikenga.meetings` 0.2.1 bundles its own copy of this meeting-recorder
sidecar, so there is no reason to install this standalone pkg alongside it.
This package is removed from the Ikenga registry (DEC-72, Round 58) and will
not accept new publishes to the catalog.

Ikenga meeting recorder sidecar managing local own-machine capture,
whisper.cpp STT engine, and Playwright bot runners.
