# @ikenga/mcp-meetings

**Retired — use [`com.ikenga.meetings`](../../apps/meetings) (bundles this).**

`com.ikenga.meetings` 0.2.1 ships its own `meetings` MCP server built from the
same tool set as this package, so there is no reason to install this
standalone pkg alongside it. This package is removed from the Ikenga
registry (DEC-72, Round 58) and will not accept new publishes to the catalog;
its only remaining npm release is a final compatibility patch for existing
installs (the 0.1.0 publish never started on Windows — see `src/index.ts`).

Model Context Protocol (MCP) server for querying meeting transcripts, search,
summaries, and recording controls.
