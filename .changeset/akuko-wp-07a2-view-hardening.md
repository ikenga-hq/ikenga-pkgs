akuko: harden the view conformance check (G-VIEW). check-view now clicks the way a browser does (pointer and mouse down/up before the click), sets every value of unmarked dropdowns, checkboxes, radios and ranges, double-clicks, fires the page-leaving events, and runs animation frames and the page clock on its fake timer, so pages that approve on those all fail. Hidden-money checks resolve CSS custom properties and catch more ways of hiding text. The decision writer is now v2: it no longer posts an empty list on load, which overwrote decisions in Ikenga after a pane remount, and pages must inline the current writer (`stale-writer`). Every host's `publishView` now refuses a decision-writing view whose exact HTML is not on a conformed list; read-only views publish freely, and check-view reports them SKIP. The conformance hash (check-view@2) now ignores the embedded akuko-project data, so a checked page still conforms when published with the real project; re-record existing entries. `check-view --ship views/conformed.json` records a new version of one of the skill's own views. After review: the project block is found the way a browser parses it and anything ambiguous fails `bad-project-block` (the raw page is then hashed); the idle and click checks run in Ikenga and as a local file too, let ten minutes of the page clock run after every click, fire observers, and click cards and the page body; pages may not embed frames (`iframe-in-view`) or post an empty decisions list in Ikenga (`empties-ikenga-store`); check-view and the publish gate share one "writes decisions" predicate (reading decisions is fine); `--ship` records only into the skill's own list.
